Dein Spiel geht online

Mach einfach einen Schritt nach dem anderen und hak ihn ab. Alles, was du eintippen musst, kannst du mit einem Klick kopieren. Dein Fortschritt bleibt in diesem Browser gespeichert.

Teil 1 · Spiel öffnen ca. 3 Minuten

SCHRITT 1

Spieldatei herunterladen

Lade die Datei MeteorHeist.rbxlx herunter. Fragt GitHub nach einem Login, melde dich an. Alternativ nimmst du die Datei aus dem Chat mit Claude.

⬇ MeteorHeist.rbxlx herunterladen

Speicher sie dir am besten auf den Desktop, dann findest du sie gleich wieder.

SCHRITT 2

In Roblox Studio öffnen

Roblox Studio starten. Ganz oben links:

File›Open from File…

Dann MeteorHeist.rbxlx auswählen und öffnen.

Die Welt sieht erst leer aus. Das ist richtig so: Die Map baut sich beim Starten von allein auf.

Teil 2 · Ausprobieren ca. 5 Minuten

SCHRITT 3

Auf Play drücken

Oben auf den Knopf ▶ Play klicken (oder Taste F5). Du landest in deiner eigenen Base.

  • Lauf zur Alien-Parade in der Mitte und halte E an einem Ei: Du klaust es gratis und trägst es über dem Kopf. Renn damit in deine Base. (Mit F kaufst du es, dann fliegt es von allein hin.)
  • Warte kurz: In deiner Base schlüpft ein Alien aus dem Meteor. Erst das Alien bringt Geld.
  • Lauf über das grüne Feld (oder einen deiner Plätze), um dein Geld einzusammeln.
  • Klick rechts auf 🏃 Laufbänder und lauf auf dem Holz-Laufband: Du sammelst Schritte und wirst schneller.
  • Klick rechts auf 🎡 Glücksrad und dreh einmal. Daneben warten 🎁 Geschenke und 📜 Aufgaben.
  • Drück P für dein Admin-Panel. Spawn zum Spaß einen 👑 Admin-Meteor oder starte einen 🥚 Egg Rush.
  • Drück G zum Fliegen: Leertaste = hoch, Shift = runter, nochmal G = landen.
SCHRITT 4

Test beenden

Oben auf den roten Knopf ■ Stop klicken.

Steht unten im Fenster Output roter Text? Kopier ihn und schick ihn Claude im Chat, dann wird es repariert. (Fenster öffnen: View›Output)

Teil 3 · Veröffentlichen ca. 10 Minuten

Auf Roblox hochladen

File›Publish to Roblox

Fragt Studio nach einem Genre, nimm Simulation (Untergenre Tycoon). Dann auf Create klicken.

SCHRITT 6

Speichern einschalten (wichtig!)

Home›Game Settings›Security

Den Schalter Enable Studio Access to API Services einschalten und unten auf Save klicken.

Ohne diesen Schritt werden Spielstände nicht gespeichert.

SCHRITT 7

8 Spieler pro Server einstellen

Es gibt genau 8 Basen, deshalb maximal 8 Spieler pro Server.

Game Settings›Places›⋯›Edit

Max Players auf 8 stellen und Save klicken.

Je nach Studio-Version heißt das Feld auch „Server Size“. Findest du es nicht, geh im Browser auf create.roblox.com/dashboard/creations, dann dein Spiel › Places › den Place anklicken.

SCHRITT 8

Icon und Vorschaubilder hochladen

Die fertigen Bilder liegen bereit. Öffne den Ordner und lade jedes Bild herunter (Bild anklicken › Download-Knopf).

🖼 Bilder-Ordner öffnen

Game Settings›Basic Info

  • Bei Game Icon: spiel-icon.png
  • Bei Thumbnails: thumbnail-1.png, thumbnail-2.png, thumbnail-3.png

Dann Save. Neue Bilder prüft Roblox kurz, bevor alle sie sehen.

SCHRITT 9

Spiel öffentlich machen

Game Settings›Permissions

Bei Playability auf Public stellen und Save klicken. Ab jetzt kann jeder dein Spiel finden und spielen.

Vorher stellt Roblox dir ein paar Fragen zu deinem Spiel (Fragebogen „Maturity & Compliance“). Antworte ehrlich:

  • Gewalt: Es gibt nur einen Bonk-Schläger (auch als Super-Bonk), der Spieler wegschubst, und eine Falle, die Diebe 3 Sekunden einfriert. Kein Schaden, kein Blut, keine echten Waffen.
  • Paid Random Items (für Robux etwas Zufälliges kaufen): Ja, wegen „Zufälliger Legendary/Mythic Meteor“, der Glücksrad-Drehs und dem Starter-Paket (zufälliges Legendary-Ei).

Danach einmal im Browser auf roblox.com unter Create › Creations dein Spiel öffnen und auf Play drücken. Dein erstes eigenes Roblox-Spiel ist online! 🎉

Teil 4 · Robux verdienen wenn das Spiel läuft

SCHRITT 10

Gamepasses anlegen

Im Browser: create.roblox.com/dashboard/creations › dein Spiel › Monetization › Passes › Create a Pass.

  1. Bild hochladen, Name und Beschreibung von unten kopieren, Create Pass.
  2. Den neuen Pass anklicken › Sales › Item for Sale einschalten › Preis eintragen › Save.
  3. Die ID kopieren (Zahl in der Adresszeile) und unten in die Vorlage schreiben.
SCHRITT 11

Developer Products anlegen

Gleiche Seite: Monetization › Developer Products › Create. Bild, Name, Beschreibung und Preis eintragen, speichern, ID kopieren.

SCHRITT 12

IDs an Claude schicken

Kopier diese Vorlage, schreib hinter jedes = die passende ID und schick sie Claude im Chat. Claude trägt alles ein, du bekommst eine neue Datei.

Vorlage

        
Neue Datei öffnen (File›Open from File…), dann:

        
File›Publish to Roblox As…› dein Spiel auswählen ›Overwrite

        
Wichtig ist „Publish to Roblox As…“ mit deinem bestehenden Spiel. Sonst entsteht ein zweites, neues Spiel.
