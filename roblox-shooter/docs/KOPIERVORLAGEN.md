# CLUTCH CLASH: Kopiervorlagen

## Wofür ist diese Datei?

Hier steht **alles, was du beim Veröffentlichen eintippen musst**.
Du musst dir nichts selbst ausdenken.
Kopieren, einfügen, fertig.

Am Ende bekommt jeder Gamepass und jedes Produkt von Roblox eine **ID** (eine lange Zahl).
Die schickst du Claude mit der Vorlage ganz unten (Abschnitt 9).
Dann trägt Claude alle IDs für dich ein.

---

## 📋 So kopierst du richtig

- Jeder **graue Kasten** ist genau ein Text zum Kopieren.
- Fahr mit der Maus über den Kasten. Oben rechts erscheint ein kleiner **Kopier-Knopf** (zwei Quadrate). Klick drauf.
- Geh zu Roblox, klick in das Feld und drück **Cmd + V**.
- Kein Knopf da? Dann markier den Text im Kasten mit der Maus und drück **Cmd + C**.

## 📖 Kleine Wörterliste

| Wort | Was es heißt |
|---|---|
| **Robux (R$)** | Das Geld von Roblox. Spieler bezahlen damit. Du bekommst ca. 70 % davon, Roblox behält ca. 30 %. |
| **Gamepass** | Wird **einmal** gekauft und gilt **für immer**. Beispiel: VIP. |
| **Developer Product** | Kann man **immer wieder** kaufen. Beispiel: ein Gem-Paket. |
| **ID** | Die Nummer, die Roblox jedem Pass und Produkt gibt. Das Spiel braucht sie. |
| **Config-Key** | Der Name im Code (z. B. `VIP` oder `Gems120`). Daran weiß Claude, wo die ID hingehört. Du musst ihn bei Roblox nirgends eintippen. |
| **Gems** | Die Premium-Währung im Spiel. Damit kauft man Kosmetik (Aussehen), nie Waffen oder Coins. |
| **Icon** | Das kleine, quadratische Bild von deinem Spiel (oder von einem Pass). |
| **Thumbnail** | Ein großes Vorschaubild. Spieler sehen es, bevor sie dein Spiel öffnen. |
| **Creator Dashboard** | Die Roblox-Webseite für Spiele-Macher: https://create.roblox.com/dashboard/creations |
| **XP** | Erfahrungspunkte. Genug XP = nächstes Level. Boosts machen nur XP schneller, nie Coins. |
| **Clutch Pass / Stufe** | Saison-Belohnungen in 30 Stufen. Gratis-Spur für alle, Premium-Spur mit dem Pass-Produkt. |
| **Wrap, Skin, Charm, Finisher, Tracer** | Aussehen (Kosmetik): Wrap = Lackierung, Skin = andere Form, Charm = Anhänger, Finisher = Effekt beim Pop, Tracer = Farbe der Schuss-Spur. |
| **Baseplate** | Die leere Start-Welt in Studio. Du veröffentlichst sie zuerst (`ANLEITUNG.md` Kapitel 7.1). |
| **Localization** | Übersetzung. Dort trägst du Texte für eine zweite Sprache ein. |

## 1. 🏷️ Spielname und Untertitel

**Beim allerersten Veröffentlichen** (leere Baseplate, siehe `ANLEITUNG.md` Kapitel 7.1) nimmst du den einfachen Namen:

```
Clutch Clash
```

**Danach** änderst du ihn auf den richtigen Titel (mit Such-Wörtern):

```
CLUTCH CLASH Duels [1v1-4v4]
```

**Wo ändern?** In Studio: **Home → Game Settings → Basic Info → Name** → **Save**.
Oder im Creator Dashboard: dein Spiel → **Configure** (Einstellungen) → **Basic Info**.

**Ersatz-Namen**, falls der Name schon belegt ist (nimm nur einen):

```
Blaster Clash Duels [1v1-4v4]
```

```
Pop Duel [1v1-4v4]
```

**Untertitel / Spruch** (für Thumbnails, Social Media oder den Anfang der Beschreibung):

```
Sofort-Duelle. Null Warten. Reiner Skill.
```

```
Instant duels. Zero waiting. Pure skill.
```

> 💡 Bei einem Update kannst du vorne „[UPDATE]“ dazuschreiben, z. B. `[UPDATE] CLUTCH CLASH Duels [1v1-4v4]`.

> 💡 Beide Texte sind kürzer als 1000 Zeichen. Mehr erlaubt Roblox nicht.
> 💡 Der Code `LAUNCH` läuft am **31.01.2027** ab. Danach diese letzte Zeile löschen oder einen neuen Code von Claude eintragen lassen.

**Wo eintragen?**
- Die **deutsche** Beschreibung kommt ins Feld **Description**: **Home → Game Settings → Basic Info** (dort, wo auch der Name steht).
- Die **englische** Beschreibung ist ein Extra. Im Creator Dashboard bei deinem Spiel gibt es den Bereich **Localization** (heißt: Übersetzung).
  Dort **English** hinzufügen und den englischen Text eintragen.
- Schau dort auch nach der **Source Language** (Ausgangssprache). Steht da **English**? Dann stell sie zuerst auf **German** (Deutsch).
  Sonst denkt Roblox, dein deutscher Text ist Englisch.
- Zu kompliziert? Dann nimm nur eine Beschreibung. Für mehr Spieler weltweit ist die **englische** besser.

## 5. 🎟️ Gamepasses (4 Stück)

**So legst du einen Gamepass an:**

1. Öffne das **Creator Dashboard** und klick auf dein Spiel.
2. Links: **Monetization** → **Passes** → **Create a Pass**.
3. **Bild** hochladen (512 × 512), **Name** einfügen, **Beschreibung** einfügen → **Create Pass**.
4. Klick den neuen Pass an. Links: **Sales**.
5. **Item for Sale** einschalten → **Preis** eintippen → **Save Changes**.
   (Fragt Roblox den Preis schon beim Erstellen? Dann gleich dort eintragen.)
6. ID holen: Bei dem Pass auf **⋯** (drei Punkte) klicken → **Copy Asset ID**.
7. Die ID unten in die Vorlage „Schick mir das zurück“ (Abschnitt 9) einfügen.

> 💡 Steht die ID nicht im Menü? Dann schau in die Adresszeile vom Browser. Dort stehen zwei lange Zahlen. Die **zweite** ist die ID vom Pass.

> 💡 Trag bei Roblox die **englische** Beschreibung ein. Die deutsche ist für dich zum Verstehen (oder für die Übersetzung unter **Localization**).
> Im Spiel selbst zeigt der Shop eigene Texte auf Deutsch oder Englisch.

## 7. ❓ Fragebogen-Hilfe (Maturity & Compliance)

Bevor dein Spiel **öffentlich** (Public) wird, stellt Roblox dir Fragen zu deinem Spiel.
Der Fragebogen heißt **Maturity & Compliance Questionnaire**.
Roblox bestimmt damit, ab welchem Alter das Spiel passt.

**Wo?** Creator Dashboard → dein Spiel → links **Audience** → **Maturity & Compliance**.

**Antworte immer ehrlich.** Das hilft dir bei CLUTCH CLASH:

- **Gewalt:** Ja, aber **mild**. Spieler schießen mit **bunten Spielzeug-Blastern** (orange Spitze) aufeinander. Die Gewalt ist wiederholt, aber
  **unrealistisch**: Wer besiegt ist, **zerplatzt sofort in Konfetti** („POP!“) und ist in der nächsten Runde wieder da. Es gibt **keine Leichen**.
- **Blut / Gore:** **Nein.** Treffer zeigen Cartoon-Sterne und weiße Puffs.
- **Realistische Waffen:** **Nein.** Nur Spielzeug-Blaster, keine echten Waffennamen.
- **Paid Random Items** (heißt: Man bezahlt mit Robux und bekommt etwas Zufälliges): Hier musst du **JA** antworten. Grund:
  - Die **Blaster-Kiste S1** kann man mit **Gems** öffnen. Gems gibt es für Robux.
  - Die Chancen stehen **vor** dem Kauf im Spiel (Knopf „Details & Quoten“). Nach 29 Öffnungen ohne Legendary kommt garantiert eins.
  - In Ländern, in denen Roblox das verbietet, ist die Gem-Kiste **automatisch versteckt** und wird vom Server abgelehnt.
  - Kein Robux-Produkt selbst ist zufällig. Mit gratis **Schlüsseln** öffnen ist kein bezahlter Zufall.
- **Glücksspiel um echtes Geld:** **Nein.** Das Gratis-Glücksrad kostet nichts, bezahlte Drehs gibt es nicht.
- **Chat:** Ja, der normale Roblox-Text-Chat (Roblox filtert ihn). Kein eigener Sprach-Chat.
- **Grobe Sprache, Alkohol, Drogen, Horror, Romantik:** **Nein.** (Die „Heil-Limo“ ist Limonade.)

**Ergebnis:** Das Spiel sollte als **Mild** eingestuft werden.
